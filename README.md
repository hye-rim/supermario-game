# 슈퍼마리오 🍄

달리고 뛰어서 **깃대**까지 가는 마리오 풍 플랫폼 게임(코스 4개). 캐릭터·그림·소리는 모두 이 게임에서 새로 그린 것이다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 `index.html` + `levels.js` + `logic.js` + `game.js` 만으로 돈다.

- **조작**: ← → 걷기 · 스페이스(Z, ↑) 점프(**오래 누를수록 높이**, 짧게 누르면 낮게) · X(Shift) 달리기·불꽃 · P 일시정지 · M 소리. 폰은 왼쪽 ◀ ▶, 오른쪽 점프와 달리기·불꽃 버튼
- **움직임**: 걷기 88px/s, 달리기 135px/s, 점프 약 4칸 높이. 달리면서 뛰면 약 7칸, 걸으면서 뛰면 약 5칸을 날아간다. 뜬 동안에도 조금 방향을 바꿀 수 있고, 발판을 막 떠난 뒤 0.08초 안에는 뛸 수 있다
- **블록**: `?` 머리로 치면 동전(200점), `M` 은 작을 때 버섯·클 때 불꽃 꽃, 벽돌은 작으면 튕기기만 하고 크면 부서진다(50점). 블록 위에 서 있던 적은 뒤집힌다
- **변신**: 버섯을 먹으면 커진다(적에게 한 번 맞아도 작아질 뿐). 꽃을 먹으면 불꽃 마리오가 되어 달리기 버튼으로 불꽃(최대 2개)을 쏜다. 작을 때 맞으면 목숨을 잃는다. 맞은 뒤 2초는 깜빡이며 안전
- **적**: 굼바는 밟으면 납작해진다(100·200·400·800·1000점, 땅에 닿기 전까지 이어서 밟을수록 커짐). 쿠파는 밟으면 등껍질이 되고, 등껍질에 닿거나 밟으면 차서 굴러가며 다른 적을 쓰러뜨린다(굴러가는 걸 밟으면 멈춘다). 화면에 가까워지면 깨어난다
- **깃대**: 닿으면 코스 클리어. 높은 곳을 잡을수록(100~5000점), 남은 시간 1초당 50점. 4코스(초원·동굴·하늘 구름·성)를 모두 깨면 승리
- **목숨**: 3개(연습은 9개). 구멍에 빠지거나 시간이 끝나거나 작을 때 맞으면 한 개를 잃고 **그 코스를 처음부터** 다시. 동전 100개마다 하나, 10만 점마다 하나. 깬 코스는 처음 화면에서 골라 시작할 수 있다(`smStage` 에 저장)
- 화면이 가려지면(탭 전환) 저절로 멈춘다. 최고 점수는 `smBest`(로비 표시용). 튜토리얼(`?tutorial=1`)에서는 시간 제한이 없고 목숨이 9개다
- **코스 규칙**(시험으로 확인): 구멍 폭 4칸 이하, 땅 구간 3칸 이상, 시작은 안전한 평지, 적은 땅 위에서 시작하고 **파이프 바로 오른쪽(착지 자리)에는 두지 않는다**, 파이프 높이 3칸 이하, 블록은 닿는 높이, 각 코스에 버섯 블록이 앞쪽에 있다

규칙은 `logic.js`(화면 없이 Node 로 시험), 코스는 `levels.js`, 화면·입력·소리는 `game.js`. 시험은 `node --test`(디렉터리): `test/logic.test.js`(코스 4개 유효성, 땅·구멍, 걷기·달리기 속도, 벽·화면 왼쪽 끝, 점프 높이(길게·짧게)와 공중 점프 불가, 걸어서 4칸·달려서 6칸 구멍 넘기, `?`·버섯·벽돌 블록, 버섯·꽃과 크기 변화, 밟기와 연속 점수, 옆에서 닿으면 작아지거나 죽음·무적, 굼바 걷기와 구멍, 적이 깨어남, 쿠파 등껍질과 차기·굴러가는 등껍질, 불꽃, 동전과 100개, 블록 위의 적 뒤집기, 깃대와 높이·시간 점수, 마지막 코스 승리, 시간 초과·죽으면 처음부터·목숨 0, 추가 목숨, 연습 모드, 무작위 플레이 24판 불변 조건).
